5.4. Обработка массивов подпрограммами. Задача 1.

Даны одномерный массив P из n элементов и двумерный массив A: n строк
и n столбцов. Выделить подзадачи, реализовать их подпрограммами и
собирать из них программу решения поставленной задачи. Предусмотреть
подпрограммы ввода/вывода. Глобальными переменными не пользоваться!
